# R 16 HD automated config. 4 visual proxy

Generated by `Tools/Blender/build_r16_hd.py` in Blender 5.1. Blender coordinates use metres with vehicle axes **+X forward, +Y left, +Z up**. The FBX exporter uses `apply_unit_scale=False` and `FBX_SCALE_NONE`; Unreal 5.8 then converts metre source geometry to centimetres exactly once.

All C++ visual components use relative scale `(1,1,1)`. `*_UE_Normalized.fbx` remains a legacy Blender-side reference and is not used by `AAutomatedForklift`.

## Unreal centimetre Bounds audit

Run `Tools/Unreal/AuditR16HDAssets.py` with Unreal's Python commandlet after an import. The verified Bounds are: body `266 x 129 x 189.5cm`; drive wheel `36 x 14.18 x 36cm`; load wheel `28.5 x 11 x 28.5cm`; each complete fork `115 x 10 x 47.25cm`. The requested horizontal fork tine is exactly `115 x 10 x 4.5cm`; the full fork Bound is taller because it includes the vertical heel.

The drive wheel centre is `(-72cm, 0)`, load-wheel centres are `(+73.3cm, +/-64cm)`, giving the confirmed `145.3cm` wheelbase. `Underframe_Actual` has its mast and centre clearance geometry at 4.0cm and 4.4cm above ground. The C++ visual meshes have no collision; existing body and fork collision components remain authoritative.
