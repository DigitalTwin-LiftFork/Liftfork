# Liftfork — 자동화 지게차 시뮬레이터

Unreal Engine 5.8과 C++로 개발하는 자동화 지게차 시뮬레이터입니다. Linde R 16 HD automated config. 4를 참고하며, 현재는 지게차 한 대의 외형과 수동 조작 기능을 구현했습니다.

## 현재 구현 내용

- C++ 기반 주행·조향·인양·하강·리치·포크 좌우 이동
- 카메라 회전 및 확대·축소
- Blender로 제작한 부품별 FBX 모델과 빨강·검정 재질 적용
- 구동 바퀴 1개 + 하중 바퀴 2개로 외형 구성
- 외형 메시와 충돌·가동부 구조 분리

## 이번 커밋

- 지게차 C++ 코드와 Map1 테스트 레벨 추가
- 지게차 메시·재질 에셋 및 모델 제작 관련 파일 추가
- FBX 적용 과정에서 발생한 크기·부품 위치 문제 수정

## 실행 및 조작

UE 5.8과 C++ 빌드 환경이 필요합니다. Git LFS 파일을 내려받은 뒤 `DigitalTwin.uproject`를 빌드하여 열고, Map1에서 Play를 실행합니다.

| 키 | 동작 |
|---|---|
| W / S | 전진 / 후진 |
| A / D | 조향 |
| E / Q | 인양 / 하강 |
| R / F | 리치 전후 이동 |
| Z / C | 포크 좌우 이동 |
| P | 지게차 앞에 팔레트 생성 |
| G | 정렬된 팔레트 인양 / 포크를 내린 뒤 내려놓기 |

생성 팔레트는 120 × 100 cm 크기이며, 기존 포크 이동 키로 진입하고 조작합니다.

## 향후 구현

- 팔레트 적재물과 고급 물리 상호작용
- 출발·도착 영역 선택에 따른 자동 작업 생성
- 지게차 2대 운용 및 돌발 상황 대응

※ 현재 외형에는 단순화·추정한 부분이 포함되어 있으며, 자동 운행과 팔레트 운반은 아직 구현 전입니다.
