# 공장 운반 작업

## 실행

1. 이 폴더의 start.ps1을 PowerShell로 실행하거나 Python 3.10 이상에서 server.py를 실행합니다.
   python server.py
2. 브라우저에서 http://127.0.0.1:8765 를 엽니다.
3. Unreal의 Factory 맵을 플레이합니다.
4. 작업 화면에서 팔레트 번호와 빈 선반을 선택하고 운반을 등록합니다.
5. 해당 팔레트를 수동으로 집어 포크 높이 15~60cm로 맞추고 수동 조작을 멈춥니다.
6. 서버가 작업을 배정하고 지게차가 선반 이동·하역·포크 회수를 수행합니다.

등록된 팔레트가 실제로 포크에 지지된 경우에만 배정됩니다. 자동 집기는 별도 기능과 연결할 수 있습니다.
기존 Unreal의 구역·번호 버튼도 계속 사용할 수 있습니다.

## 공장

- A~F 각각 12칸 × 3층, 총 216자리
- 아래층 01~12, 가운데층 13~24, 위층 25~36
- 1층에 입고·검사/보류·생산 투입·출고·충전/주차 구역 생성
- A~C 선반은 원자재, D~F 선반은 완제품 보관으로 지정
- 바닥 구역별 경계선·팔레트 대기칸·한 방향 표지와 작업대 생성
- 중앙 주행 통로와 동쪽 보행 통로는 기존대로 확보
- 구역 표지와 바닥선은 Factory 맵에 저장되어 플레이 전 편집 화면에서도 보임
- 선반 위 빈 팔레트는 제거하고 상자와 함께 놓인 팔레트만 유지; 바닥의 빈 팔레트는 유지
- 각 팔레트에 P-번호 표시를 부착해 수동 집기 대상 식별
- 현재 운반 목적지는 선반 216자리이며, 바닥 구역은 작업 공간 표시
- 생산·검사·배터리 충전 공정의 자동 실행은 아직 연결하지 않음
- 선반 점유는 시뮬레이션의 실제 팔레트 좌표로 확인
- 팔레트 ID가 비어 있으면 플레이 중 P-001 형식으로 자동 부여
- 지속적으로 고정할 팔레트 번호는 에디터의 PalletId 속성에 지정

## 작업과 저장

상태는 queued → assigned → moving → unloading → withdrawing → completed로 진행합니다.
같은 팔레트나 선반에 작업을 중복 등록할 수 없습니다.
완료 보고 시 팔레트가 목적지에 있고 포크 적재가 해제됐는지 서버가 다시 검사합니다.
중단·취소 시 팔레트는 현장 위치에 남으며 자동으로 재시도하지 않습니다.
연결이 끊기면 배정 작업을 중단하고 상태를 기록합니다.
서버 또는 시뮬레이션을 재시작한 진행 작업은 interrupted로 처리해 재배정을 막습니다.

작업 이력은 Saved/transport.sqlite에 저장됩니다.
선반·팔레트 좌표는 Factory 플레이에서 받은 최신 상태를 사용하며 5초 넘게 끊기면 새 작업을 받지 않습니다.
입출고 구역 표시는 시뮬레이션 배치이며 실제 설비 사양 또는 실측 데이터는 아닙니다.

## API

- GET /api/state — 연결·팔레트·선반·작업
- POST /api/jobs — {"pallet":"P-001","destination":"D-20"}
- POST /api/jobs/{id}/cancel — 작업 취소 요청
- POST /api/sync — Unreal 전용 상태 보고·배정 응답

기본 서버는 로컬 컴퓨터의 127.0.0.1에만 연결됩니다.
운영 설비에 연결하려면 인증·권한·장비별 통신 규약과 장애 대응 검증이 별도로 필요합니다.

## 접점식 자동 충전

- 바닥 예시 화물 6개를 제거하고 선반 화물 54개를 유지합니다.
- 충전소에는 바닥 전극 2개, 차량 하부에는 수전 접점 2개가 있습니다. 바닥 도색은 충전 장치가 아닙니다.
- 충전소 이동 버튼 또는 잔량 20% 이하 요청 → 정밀 도킹 → 정지 → 접점 감지 및 충전기/BMS 승인 2초 → 충전 → 전류 차단 → 접점 해제 1초 순서입니다.
- 직접 충전 구역에 접근해 정차해도 도킹 및 충전을 요청합니다. 취소 후에는 구역을 벗어나거나 수동으로 재요청하세요.
- 충전소 앞 접근 구간 8m는 충전소 기준의 시뮬레이터 좌표 피드백으로 정렬합니다. 실제 도킹 센서의 측정 오차를 재현한 것은 아닙니다.
- 모델 도킹 조건: 좌우 2cm, 전후 5cm, 방향 -90도 기준 3도 이내, 수전 접점 높이 일치. 실제 제품별 사양을 대체하는 값은 아닙니다.
- 빈 포크 30cm 이하 / 리치 복귀 / 정지 / 현재 자동 작업 종료가 필요합니다.
- 전원 및 BMS 승인, 온도 0~45C 조건을 확인하고 접촉기를 닫습니다. 전원·승인·온도는 시뮬레이션 입력입니다.
- 접점 연결 중에는 주행·포크 조작을 잠급니다. 조작 또는 취소 시 전류를 먼저 끊고 접점 해제 후 주행을 허용합니다.
- 초기 80%, 정격 48V/12kWh, 최대 충전 12kW, 목표 90%, 기본 시간 1배입니다.
- 80% 이후 전력을 줄이는 CC/CV 근사 모델입니다. 실제 충전기 CAN/BMS 통신이나 전기회로 검증은 포함하지 않습니다.
- HUD와 서버에서 접점·접촉기 상태, kW/A, 도킹 및 승인 대기 이유를 확인할 수 있습니다.
- 파라미터는 TransportCoordinator에서 조절합니다. -BatteryInitialPercent=19로 초기 잔량을 지정할 수 있습니다.
- API: POST /api/charging {"action":"request"} 또는 {"action":"cancel"}.
