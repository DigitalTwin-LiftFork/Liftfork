# 다중 지게차 운용

## 사용

Factory 맵에서 Play를 시작한 뒤 플레이어가 조작하는 지게차에서 `Y`를 누르면 별도의 순찰 지게차 3대가 생성되어 편대 자동 순찰을 시작합니다. 플레이어 지게차는 생성 수에 포함되지 않으며 주행 상태도 변경하지 않습니다. 순찰 차량들은 같은 C++ 지게차 클래스로 생성되고, 각각 독립된 LiDAR, SLAM 지도, 충돌 형상, 안전 감시, 팔레트 처리 구성요소를 가집니다. 다시 `Y`를 누르면 순찰 차량 3대만 정지합니다.

차량 ID와 관제 연결 상태는 지게차 진단 패널에 표시됩니다. 순찰 차량들은 기존 지게차 주변부터 넓은 반경까지 후보 위치를 탐색해 충돌 없는 위치에 배치합니다. 3개의 빈 위치를 모두 찾지 못하면 부분 편대를 남기지 않고 생성을 취소하며, 플레이어 차량은 그대로 둡니다.

## 교착 대응

두 차량이 가까이 있고 둘 다 다른 차량에 양보 정지한 상태가 4초 이어지면, ID가 큰 차량 한 대만 기존 후진 경로 검사로 1.2m 후진을 시도합니다. 후방에 장애물이 있거나 후진이 불가능하면 안전 정지를 유지하고 상태를 표시합니다. 자동 후진은 기존 주행 복구 제한(최대 3회)을 따릅니다.

각 차량은 자신의 SLAM 지도와 위치 추정을 사용합니다. 이 구현은 차량 간 지도 정합이나 공통 통로 그래프 기반의 교차로 예약, 물류 주문/팔레트 작업 배분을 제공하지 않습니다. 따라서 좁은 통로에서는 LiDAR 안전 정지 및 제한된 교착 후진으로 대응하며, 복잡한 교차로 통행은 실제 맵에서 확인해야 합니다.

## 확인 방법

1. Factory 맵에서 Play를 실행하고 `Y`를 누릅니다.
2. 화면 로그에서 순찰 지게차 3대 생성 및 시작 메시지를 확인합니다. 플레이어 지게차는 그대로 유지됩니다.
3. 여러 지게차의 독립 순찰과 센서/지도 표시를 관찰합니다. 차량 간 간격이 좁을 때 각 차량이 먼저 정지하는지 확인합니다.
4. 두 차량을 좁은 통로에서 마주 보게 해 교착 대응을 확인합니다. 후방을 비운 상태에서는 ID가 큰 차량만 후진을 시도해야 합니다. 후방을 막으면 두 차량이 정지 상태를 유지해야 합니다.
5. `Y`를 다시 눌러 순찰 지게차 3대의 자동 주행을 정지합니다.
