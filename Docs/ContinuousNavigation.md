# 연속 센서 주행 개선 (2026-10-28)

- 기존 상단 회전 LiDAR 한 대를 유지합니다. 기본 100개 방위각 열, 열 간격 0.002초로 1회전은 약 0.2초입니다. 프레임 지연 시 실제 갱신은 느려질 수 있습니다.
- 센서의 Visibility 쿼리에서 소유 지게차만 제외합니다. 주변 물체 감지와 실제 충돌 방지는 유지합니다.
- SLAM 정합 속도와 IMU 회전으로 스캔 사이 최대 0.3초 위치를 예측하여 경로 추종에 사용합니다. 장애물 측정점도 이 예측 좌표계로 변환합니다.
- 직선 구간에서는 약 1.5m 앞을 보며 추종하고, 코너 지점은 유지합니다. 이동 가능한 전진 경로를 정지 회전보다 우선합니다.
- 정합 실패 스캔으로 지도를 덮어쓰지 않습니다. 추적 실패, 센서 지연, 충돌 위험에서는 계속 정지합니다. 정지 기능을 없애서 움직이게 만드는 변경이 아닙니다.

기존 하단 자동 탐색 UI를 사용합니다. Git 프로젝트의 지도 클릭 목적지 기능도 유지합니다. 두 작업 폴더는 서로 다른 버전이므로 해당 기능 전체를 복사해 덮어쓰지 않고 공통 주행 개선만 각각 적용했습니다.

빌드와 실제 Play 주행 검증은 별개입니다. 이번 변경의 주행 연속성 및 도착 정확도는 아직 Play에서 검증하지 않았습니다.
## 경계 정합 점수 처리

표시되는 일치율은 정합 점수이며 위치 정확도의 확률이 아닙니다. 45% 이상은 기존 판정을 유지합니다. 40~45%는 최소 12개 독립 지도 셀, 2개 이상 방위 구간, 60% 이상 근접 측정점, 작은 예측 보정, 5회 연속 일관된 후보가 모두 필요합니다. 이후 출발 안정 스캔 3회도 충족해야 합니다. 이 구간에서는 최고 속도를 30 cm/s로 제한합니다. 부족한 지지점이나 급격한 위치 변화가 있으면 계속 정지하며, 이를 일치율 숫자만 낮춰 우회하지 않습니다. 실제 정지 위치에서의 재현 확인은 아직 수행하지 않았습니다.
## 상단 장착 지도 수정

적용 폴더: Documents/GitHub/Liftfork만 변경합니다. 바탕화면 복사본은 수정하지 않습니다.

기존 문제: 지면 위 약 8m인 센서의 수평 광선이 장애물 위로 통과해도, 그 광선의 XY 투영 전체를 바닥의 빈 공간으로 기록했습니다. 동일 지도에 모든 높이의 수직면을 정합 기준으로 저장했기 때문에 낮은 선반 정합점이 빈 공간 갱신으로 지워졌습니다.

변경: 정합 기준점 집합과 주행 점유 지도를 분리합니다. 정합 기준점은 승인된 포즈의 수직면 측정만 누적합니다. 주행 빈 공간은 측정된 바닥 끝점 주변의 작은 20cm 격자 패치만 갱신하며 수평 무반사 광선으로 지우지 않습니다. 박스와 팔레트 상판도 차체 통과 높이의 장애물로 처리합니다. 동일 회전 센서에 하향 38개 고도 채널을 추가하여 약 0.2~15m 반경의 바닥을 관측합니다. 이는 센서를 추가한 것이 아니라 가상 센서 한 대의 수직 각도 구성을 확장한 것입니다. 실제 장비의 고정 채널 수를 재현한 사양은 아닙니다.

평평한 Factory 바닥 기준으로 차체 박스 하단과 2cm 간격을 이용해 바닥 높이를 보정합니다. 경사로/다층 바닥에는 별도 지면 추정이 필요합니다. 주행 지도는 실제 관측 범위만 연결하므로 가려진 공간을 자동으로 통과 가능하다고 간주하지 않습니다. 지지점 지도는 정적 구조물 위주이며 움직인 물체의 오래된 정합점 제거는 아직 없습니다. 실제 주행 결과는 빌드 결과와 별도로 확인해야 합니다.
## 랜덤 순찰

하단 **랜덤 순찰 시작** 버튼을 누르면 지도에서 현재 위치와 경로가 연결된 2.5~12m 거리의 빈 셀을 무작위로 선택합니다. 모든 이동 가능 후보가 같은 선택 확률을 갖습니다. 최근 도착한 여섯 목표 주변은 가능한 한 피하고, 다른 후보가 없으면 다시 방문할 수 있습니다. 도착 후 다음 목표를 자동 선택합니다. 장애물로 진행하지 못한 목표 주변 2m는 30초 동안 제외합니다. 10초 이상 진전이 없으면 목표를 바꾸고 연속 다섯 차례 막히면 중지합니다. 유효한 후보 자체가 없으면 정지 상태를 표시합니다.

기존 LiDAR 회피·SLAM 추적 확인·충돌 정지는 유지합니다. 랜덤 위치가 벽이나 미관측 구역 안에 생성되지는 않습니다. 지도 클릭으로 직접 지정하는 기능도 유지합니다. UI의 주행 정지 또는 수동 입력으로 중지할 수 있습니다. 이 변경은 순찰 목표 선택 방식 변경이며, 실제 장애물 회피 시연 성공은 아직 Play에서 확인하지 않았습니다.
