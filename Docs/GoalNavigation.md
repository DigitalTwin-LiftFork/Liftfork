# 자동 탐색 주행

이 폴더의 DigitalTwin.uproject를 열고 Factory에서 Play를 실행합니다.

- 하단 기존 팔레트 버튼 위의 **자동 탐색 시작**을 클릭합니다.
- LiDAR와 SLAM이 준비되면 현재 지도에서 도달 가능한 탐색 지점을 자동 선택합니다. 수동 운전이나 목적지 등록이 선행 조건이 아닙니다.
- 지점에 도착하면 다음 지점을 선택합니다. 파란색은 경로, 분홍색은 현재 탐색 목표입니다.
- 같은 버튼이 **자동 탐색 정지**로 바뀝니다. 클릭하거나 수동 주행·포크 조작을 입력하면 정지합니다.
- 자동주행용 G/H 키 연결은 제거했습니다. 기존 다른 기능의 키 설정은 유지합니다.
- 팔레트 집기나 배치를 시작하면 자동 탐색을 중지합니다.

동작: LiDAR로 관측한 빈 셀의 연결 영역을 탐색하고, 미관측 영역에 가까운 도달 가능한 지점을 선택합니다. 차체 너비를 반영해 장애물 셀을 확장하며, 주행 중에는 다층 LiDAR와 차체·포크 범위를 비교합니다. 별도의 시뮬레이션 충돌 검사로 센서 사각지대 충돌을 방지합니다. 최대 속도는 0.6 m/s입니다. 미관측 공간은 빈 공간으로 가정하지 않습니다.

일시적인 위치 추정 실패 시 정지 상태로 최대 5초 기다립니다. 회복하면 자동 재개하며, 계속 실패하면 중지합니다. 통로가 10초 이상 막히면 해당 목표 대신 다른 목표를 선택하고, 연속 5번 막히면 중지합니다. 도달 가능한 새 목표가 없으면 탐색 종료 상태를 표시하며, 이것이 공장 전체 탐색 완료를 보장하지는 않습니다. 초기 관측점 부족, 센서 사각지대, 좁은 통로 때문에 출발하지 못할 수 있습니다.

빈 지게차, 내린 포크, 접힌 리치 상태에서 사용합니다. 지도 초기화(B)는 탐색을 중지하며, 다음 시작 시 탐색 이력을 새로 시작합니다. 자동 팔레트 운반, 후진 탈출, SLAM 루프 폐쇄, 세션 간 지도 저장은 포함하지 않습니다.

빌드와 실제 Play 동작 확인은 별개입니다. 실제 주행·UI 클릭 동작은 아직 검증하지 않았습니다.
출발 안정화: 연속 3회 정합 성공 후 주행을 허용합니다. 위치 추정 대기 문구에 유효 수평 측정점 수, 정합 상태와 프레임 시간이 표시됩니다. 기본 수평 스캔은 360개이며 기본 거리는 30m입니다. 이전 15m 인스턴스 설정은 실행 시 30m로 보정됩니다.
